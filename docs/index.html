Definitions, uncertainty and posterior comparison method

Reference lnZ is the stored full log evidence from the 2,000-live run. The next two columns subtract that same reference from cheap Dynesty and NISMO, respectively. Natural logarithms are used for lnZ. Each ± value is a reported statistical error; difference errors assume independent sampling noise.

JSD(P,Q) = ½ KL₂(P‖M) + ½ KL₂(Q‖M), where M = (P + Q)/2. JSD is bounded by 0–1 bits; zero means identical distributions. The headline value is the arithmetic mean of the eight one-dimensional marginal divergences. It does not measure differences in parameter correlations.

Both comparisons use common prior support, a shared reference-based Scott bandwidth per parameter, and Gaussian-smoothed histograms. Periodic φ angles wrap; other prior boundaries reflect. NISMO uses the original normalized posterior weights. Estimator settings and source hashes are in the JSON download. The reference is used only for comparison and target validation, never proposal training or sampler tuning.

The reference-split calibration compares disjoint reference subsets matching each cheap draw count. Its 5th/50th/95th percentiles describe finite-sample variation under this comparison, not confidence intervals on the measured JSD, a bias correction, or a test of NISMO mixing. NISMO weight ESS also omits chain correlations.

Paired aggregate summaries use exactly the same completed events for both methods. All 100 cheap/reference results remain in the table. Reference posteriors retain 1,000 draws per event, so all posterior comparisons have finite-reference uncertainty.

Data, thinning and matching

Each reference event retains up to 1,000 equal-weight posterior draws, sampled uniformly without replacement with selection seed 0. Original counts and exact indices are recorded in its archive. Every cheap saved draw is retained. These contours show retained samples; they do not certify convergence or coverage.

Matching is checked using injection metadata, prior/catalogue hashes, noise evidence and 32 likelihood/prior replays against the frozen cheap-event data. Original reference strain bytes were not archived, so byte identity is not claimed. Reference sampler RNG seeds are unknown; cheap sampler seed is 42.

Posterior log-likelihood columns can be ratios relative to noise. Reported log evidences above are already full evidences. No nlive=4000 result is displayed on this site.
