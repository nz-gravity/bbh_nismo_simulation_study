Data, thinning and matching

Each reference event retains up to 1,000 equal-weight posterior draws, sampled uniformly without replacement with selection seed 0. Original counts and exact indices are recorded in its archive. Every cheap saved draw is retained. These contours show retained samples; they do not certify convergence or coverage.

Matching is checked using injection metadata, prior/catalogue hashes, noise evidence and 32 likelihood/prior replays against the frozen cheap-event data. Original reference strain bytes were not archived, so byte identity is not claimed. Reference sampler RNG seeds are unknown; cheap sampler seed is 42.

Posterior log-likelihood columns can be ratios relative to noise. Reported log evidences above are already full evidences. No nlive=4000 result is displayed on this site.
